# NVIDIA Riva protocol definitions

Files under `riva/proto/` are upstream NVIDIA Riva protobuf definitions from
https://github.com/nvidia-riva/common, fetched for the hosted gRPC speech APIs.
Upstream commit reviewed: `268890b7286031a6d4950e34f7ce13ed0d4ce621`.
Preserve their SPDX copyright and license headers. They are MIT-licensed;
`riva_asr.proto` also preserves an Apache-2.0 Google attribution.

NVIDIA Build model access, model weights and API service terms are separate
from the protocol definitions' license. No model weights are bundled here.
